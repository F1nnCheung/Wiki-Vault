# AI Coding 学习计划

> 对应学习计划**第 3 周（工具实操）+ 第 7 周（Agent 框架）**：吃透四大主流 AI 代码助手，掌握 Vibe Coding 范式，部署 OpenClaw / Hermes 个人 AI Agent。

---

## 核心认知

```
2024: AI 代码补全（Copilot 模式）—— 人主导、AI 辅助
  ↓
2025: Vibe Coding（自然语言→代码）—— Agent 元年，凭感觉编程
  ↓
2026: Agentic Engineering（多 Agent 自主协同）—— 工程化落地
  ↓
未来: ID Coding（意图编程）—— 意图直接转化为软件服务
```

**三个关键概念**：

| 概念 | 一句话 | 详细 |
|------|-------|------|
| **Vibe Coding** | 用自然语言描述需求，让 AI「凭感觉」编程 | [[Wiki/wiki/concepts/vibe-coding\|概念页]] |
| **Agentic Engineering** | 多 Agent 自主规划→编写→测试→审查，人类退为架构师 | [[Wiki/wiki/concepts/agentic-engineering\|概念页]] |
| **ID Coding** | 终极愿景：意图→服务，编程语言可能消失 | [[Wiki/wiki/concepts/id-coding\|概念页]] |

## 工具选择决策树

```
你的情况？
├── 国内用户 / 预算为零
│   └── Trae（主力）+ 了解 Claude Code（进阶方向）
│
├── 海外 / 英语无障碍
│   └── Cursor（主力）+ Claude Code（攻坚）+ Codex（审查/自动化）
│
├── 架构师 / 技术负责人
│   └── Claude Code（四层体系）+ Superpowers+gstack 闭环
│
└── 想尝鲜 Agent
    └── OpenClaw（入门友好）或 Hermes（追求自进化）
```

### 推荐组合策略

```
日常编码 80%：Trae（国内）/ Cursor（海外）
  +
架构攻坚 15%：Claude Code
  +
审查/debug/批量/自动化：Codex
  +
个人助手 1%：OpenClaw / Hermes
```

## 附录 C：学习建议

1. **不要贪多**：先选一个主力工具精通，再扩展
2. **实践驱动**：每个工具学完立即用它做一个真实项目
3. **理解原理**：工具会变，MCP/Skills/Agent 核心概念通用
4. **先跑通最小闭环**：安装 → 第一个项目 → 加入规则文件 → 配置模型 → 逐步添加增强工具
