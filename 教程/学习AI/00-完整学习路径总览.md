## 一、主线路径：9 周全栈学习

### 总周期与投入

| 项目 | 说明 |
|------|------|
| 总周期 | 8 周技术学习 + 1 周创业拓展 |
| 每日投入 | 工作日 1.5h，周末 4h |
| 适用人群 | 在职软件开发工程师，具备基础编程能力 |
| 核心目标 | 第 4 周实现 AI 提效日常开发，第 8 周搭建 RAG+Agent+MCP 一体化 MVP，第 9 周将全套 AI 技能转化为商业变现能力 |

### 技术覆盖全景

| 层级 | 技术栈 | 对应周 |
|------|--------|--------|
| 基础层 | LLM 大模型基础、Prompt 提示词工程、Rule 规则约束、Skills 技能封装 | 第 1-2 周 |

### MVP 七层架构总览

第 8-9 周的 MVP 项目遵循如下七层架构：

```
1. 底层底座    → Ollama 本地模型 + 云端 API（Claude/DeepSeek 自动切换）
2. 约束层      → 全局 Rule + 可复用 Skills 技能包
3. 编码层      → Trae/Cursor 本地联动 + Vibe Coding 模式
4. 知识层      → 私有 RAG（Chroma）+ Agentic RAG 智能检索
5. 智能体层    → 单 Agent 核心调度 + Function Calling + MCP 通信
6. 应用层      → Dify 私有化后台（RAG 问答入口）+ Coze 对外分发
7. 运维层      → LLMOps（Token 监控 + 报错率 + 幻觉率）+ AI 代码安全审计
```

### 13 条避坑清单

1. 不要沉迷纯 Prompt 玩法，必须落地代码工程
2. 不要忽视 Rule 规则，无约束的 LLM 和 Agent 无法用于生产
3. Vibe Coding 不是完全甩手掌柜，架构设计永远需要人工把控
4. RAG 不要只做基础版本，必须掌握 Agentic RAG 智能检索优化
5. 低代码平台不是终点：Coze/Dify 帮你快速验证想法，生产级定制必须回到代码层
6. MCP 是 Agent 生态标准，务必提前布局
7. OpenClaw 适合短期高频自动化，Hermes 适合长期无人值守自进化——二者不可混用
8. Hermes 自进化需要搭配严格 Rule 风控
9. Function Calling 不要过度封装工具，避免 Agent 调用链路过长导致响应超时
10. Ollama 本地模型无需盲目部署超大参数量，代码场景 7B/14B 性价比最优
11. 必须做 AI 代码安全审计，拦截 AI 生成的漏洞代码、硬编码密钥
12. 生产环境务必接入 LLMOps 监控，管控 Token 开销、接口报错率、模型幻觉率
13. 不要等技术完美再考虑变现：AI 已把 MVP 成本降至趋近于零，先验证问题再开发产品

## 五、通用 Rule 规则模板（开箱即用）

复制以下模板到你的全局 AI 配置中，所有 LLM 会话自动挂载：

```markdown
# 全局 AI 调用强制规则

1. 身份定位：你是资深软件开发工程师，输出内容贴合工业级开发标准
2. 输出约束：代码优先，禁止冗余解释，所有代码必须可直接运行，标注依赖版本
3. 格式约束：严格使用 markdown 格式，代码块标明编程语言
4. 幻觉约束：不确定的内容直接告知，禁止编造接口、参数、文档
5. 会话约束：自动记忆上下文开发需求，无需用户重复描述项目背景
6. 工具约束：Agent 调用工具单次不超过 3 次，复杂任务自动拆分分步执行
```
