# 程序员专属AI全栈系统化学习计划（2026优化版）

> 基于原版 8 周计划的深度优化，根据知识库已有 50+ 篇深度文章和教程体系重组内容结构。
> 优化要点：内容密度调整 · 低代码平台（Coze/Dify）融入 RAG+Agent 学习 · 补充 2026 关键概念 · 对接知识库资源 · 按角色分层路径

---

## 一、计划总览

### 1. 适用人群

在职软件开发工程师，具备基础编程能力（前后端均可），想要把 AI 融入日常开发、掌握 AI 编码工具、自研 AI 应用与智能体、落地企业级 LLM 工程方案，拒绝碎片化学习，打通从提示词到 AI 原生架构的全链路能力。

### 2. 全覆盖核心技术清单

| 层级 | 技术栈 |
|---|---|
| **基础层** | LLM 大模型基础、Prompt 提示词工程、Rule 规则约束、Skills 技能封装 |
| **应用层** | Vibe Coding 自然语言编程、AI 编码工具（Cursor / Trae / Claude Code / Codex） |
| **知识层** | RAG 检索增强生成、Agentic RAG 智能检索、向量数据库、混合检索 |
| **智能体层** | AI Agent 核心架构、Agent 记忆/压缩/自进化、Agentic Engineering、Function Calling |
| **低代码层** | Dify（企业私有化 RAG+Agent 平台）、Coze（可视化 Agent 编排+快速分发） |
| **协议层** | MCP 多智能体通信协议 |
| **框架层** | OpenClaw（轻量自动化 Agent）、Hermes Agent（自进化 Agent）、ECC（一站式 Harness） |
| **运维层** | Ollama 本地私有化部署、LLMOps 大模型运维、KV 缓存 & 上下文优化、AI 代码安全审计 |

### 3. 周期与每日投入

- **总周期**：8 周（循序渐进，适配程序员下班/周末碎片化学习）
- **每日投入**：工作日 1.5h，周末 4h
- **核心目标**：第 4 周实现 AI 提效日常开发，第 8 周搭建 RAG+Agent+MCP 一体化 MVP

### 4. 相比原版的核心优化

1. **内容密度调优**：原版第 1 周（LLM+Prompt+Rule+Skills 四合一）拆为两周，给概念消化留足时间
2. **低代码平台重新定位**：Coze/Dify 从"前置"改为"与 RAG/Agent 同步学习"，先懂原理再上平台
3. **第六周解耦**：原版一周塞 7 个大主题，现拆为两周聚焦
4. **补充 2026 关键概念**：Agentic Engineering、Harness Engineering、Agent 记忆/压缩、ID Coding
5. **对接知识库资源**：每周标注知识库已有深度文章和教程链接
6. **按角色分层**：国内初学者 / 海外开发者 / 架构师 三条学习路径

## 二、分阶段详细学习路线（8 周优化版）

### 第一阶段：筑基期（第 1 周）—— LLM 底层认知 + Prompt 工程核心

#### 本周核心目标

搞懂大模型运行逻辑，精通程序员专属 Prompt 写法，解决 AI 代码幻觉、输出不规范问题。**本周聚焦 LLM 理论和 Prompt 两项，Rule/Skills 留到第 2 周。**

#### 核心知识点

- **LLM 大模型基础**：Transformer 极简原理（不求数学推导）、上下文窗口、Token 机制、模型幻觉成因、开源/闭源模型选型（Claude、GPT-4o、DeepSeek、Qwen）
- **Prompt 提示词工程（程序员专项）**：零样本/少样本提示、CoT 思维链、Few-shot 代码示例、角色定制提示、结构化输出 Prompt、代码 Debug 专属 Prompt

#### 每日学习任务

| 天数 | 学习内容 | 实战产出 |
|---|---|---|
| Day 1-2 | LLM 基础理论、Token 与上下文原理、代码场景模型选型 | 输出《程序员大模型选型手册》，区分编码/问答/长文本场景 |
| Day 3-4 | 通用 Prompt 框架（CRISPE/ROLE）、代码专用 Prompt 模板 | 沉淀 8 套可直接复用的开发 Prompt |
| Day 5-7 | 需求拆解 Prompt、Bug 修复 Prompt、代码优化 Prompt 实战 | 输出一套「零调试生成工业级代码」的完整 Prompt 模板 |

#### 本周必做实战

编写一套代码生成 Prompt：要求 AI 只输出可直接运行代码、附带极简注释、遵循团队规范、禁止多余话术。

### 第二阶段：约束与技能期（第 2 周）—— Rule 规则体系 + Skills 技能封装

#### 本周核心目标

掌握 Rule 规则约束（根治 AI 自由发挥），将高频开发能力封装为可复用 Skills，搭建个人 AI 技能库。

#### 核心知识点

- **Rule 规则体系**：系统级硬规则 vs 会话级软规则、代码输出强制规则、安全风控规则、Agent 运行约束规则
- **Skills 技能封装**：将高频开发动作封装为标准化 AI 技能包（接口生成、SQL 编写、代码重构、单元测试生成）

| Day 6-7 | Skills 封装实战 | 搭建个人 AI 技能库，包含 6-8 个开发常用 Skill |

### 第三阶段：工具实操期（第 3 周）—— AI 编码工具全栈 + Vibe Coding

#### 本周核心目标

吃透四大主流 AI 代码助手，理解 Vibe Coding 新型编程范式，实现自然语言驱动完整项目开发。

#### 核心知识点

- **Vibe Coding**：核心理念（人做架构决策，AI 做代码落地）、长会话连续开发、需求模糊场景下的迭代开发
- **四大工具差异化精通**：
  - **Trae**：字节免费 IDE，国内首选，四种模式（Chat/Builder/SOLO/IDE）
  - **Claude Code**：终端 CLI，百万 Token 上下文，最强自主编程能力
  - **Cursor**：AI 原生 IDE，Tab 补全、Composer、Background Agents
  - **Codex**：OpenAI 统一 Agent 平台，token 效率 4 倍优势，适合审查/批量/自动化
- **工具组合策略**：日常编码用 Trae/Cursor，架构攻坚用 Claude Code，审查/Debug/自动化用 Codex

#### 每日学习任务

| 天数 | 学习内容 | 实战产出 |
|---|---|---|
| Day 1 | Trae 全功能实操：安装、四种模式、MCP 配置、CUE 补全 | 配置 Trae 专属工作区规则 |
| Day 2 | Claude Code 实操：安装、核心命令、MCP/Skills 配置 | 用 Claude Code 完成一个后端模块重构 |
| Day 3 | Cursor 实操：Tab/Cmd+K/Composer/Background Agents | 配置 `.cursorrules` 项目规则 |
| Day 4 | Codex 实操：Plan 模式、Steering、AGENTS.md、Automation | 用 Codex 完成代码审查 + 批量重构 |
| Day 5-7 | Vibe Coding 完整流程 | 纯自然语言完成一个 Todo 管理系统（前后端） |

### 第四阶段：知识层 + 低代码实战（第 4 周）—— RAG 全链路 + Dify 私有化部署

#### 本周核心目标

理解 RAG 检索增强生成的完整链路，**同步基于 Dify 实践 RAG 管线的搭建**——先懂原理，再用低代码平台快速落地，二者互为表里。

#### 核心知识点

- **RAG 核心流程**：文档切片 → Embedding 向量化 → 向量数据库存储 → 相似度检索 → 上下文拼接 → LLM 生成
- **关键优化点**：切片策略（固定大小 vs 语义分割）、重排序 Rerank、混合检索（BM25 + 向量）、幻觉抑制
- **Dify 平台**：开源可私有化部署、可视化 RAG 管线配置、自定义 Embedding 模型、API 对接、权限管理

#### 每日学习任务

| 天数 | 学习内容 | 实战产出 |
|---|---|---|
| Day 1-2 | RAG 理论基础：文档加载→切片→Embedding→向量库→检索→生成 | 理解 RAG 全链路每个环节的作用和常见坑 |
| Day 3 | 向量数据库选型：Chroma（轻量）vs Milvus（生产级）vs Pinecone（云托管） | 本地部署 Chroma 并跑通第一个检索demo |
| Day 4-5 | **Dify 私有化部署 + RAG 管线搭建** | 私有部署 Dify，搭建团队代码知识库问答机器人 |
| Day 6-7 | RAG 进阶优化：混合检索、Rerank、切片策略调优、幻觉抑制 | 上传过往项目代码，实现「旧项目逻辑问答」私有 RAG |

#### 学习心法

> 💡 **为什么先讲 RAG 再上 Dify？** 原版计划将 Coze/Dify 放在 RAG 和 Agent 之前，学生会在不理解底层原理的情况下「盲操」平台。优化后顺序：先理解 RAG 检索链路 → 再用 Dify 的 RAG 管线做可视化实践 → 理解 Dify 背后自动帮你做了什么。这样当你需要突破 Dify 的能力边界时，你知道底层该怎么手写。

### 第五阶段：智能体 + 低代码实战（第 5 周）—— AI Agent 原生开发 + Coze 可视化编排

#### 本周核心目标

理解 Agent 自主规划、工具调用、记忆能力，**同步基于 Coze 实践 Agent 可视化编排**——手写 Agent 核心代码 + Coze 快速搭建，两条腿走路。

#### 核心知识点

- **Agent 核心架构**：感知 → 规划 → 工具调用 → 记忆（短期+长期）→ 反思
- **Agentic Engineering**（2026 Karpathy 提出）：多 Agent 自主规划→编写→测试→审查，人类退为架构师
- **Harness Engineering**：Agent = Model + Harness，理解生成-评估分离的行业共识
- **Coze 平台**：可视化 Agent 编排、插件市场、工作流设计、一键发布网页/小程序/API、多模型切换

#### 每日学习任务

| 天数 | 学习内容 | 实战产出 |
|---|---|---|
| Day 1-2 | Agent 核心概念：Agentic Engineering、Harness Engineering、Agent 记忆系统（三层记忆）、上下文压缩 | 理解 Agent 从 L1（对话）到 L5（多 Agent 协同）的能力层级 |
| Day 3-4 | Agent 原生开发：规划模块 + 工具调用（Function Calling）+ 短期记忆 + 反射机制 | 手写一个基础 Agent，能调用 3+ 工具完成多步任务 |
| Day 5-6 | **Coze 可视化 Agent 编排** | 搭建个人开发助手 Agent，集成代码解释+SQL生成+接口调试技能，发布 API 供本地调用 |
| Day 7 | Agent + Coze 串联实战 | 先用 Coze 快速原型，再将核心逻辑手写为 Agent 代码，理解平台 vs 自研的边界 |

#### 学习心法

> 💡 **Coze 不是"玩具"，是 Agent 思想的速成教具**。通过 Coze 的可视化编排，你能在 1 小时内直观理解 Agent 的工具调用、条件分支、记忆存储。然后回到代码层手写 Agent 时，你能清晰地知道每个模块对应 Coze 中哪个节点。

### 第六阶段：通信协议 + 本地部署（第 6 周）—— MCP 协议 + Function Calling + Ollama

#### 本周核心目标

掌握 MCP 多智能体通信协议、Function Calling 底层机制、Ollama 本地私有化部署。**本周聚焦三个强关联主题，不再像原版那样塞 7 个大主题。**

#### 核心知识点

- **MCP 协议**：统一通信标准、消息格式规范、状态同步、任务分发、结果汇总、Client-Server 架构
- **Function Calling**：Agent 调用工具的底层基础、硬编码工具调用 vs LLM 原生函数调用、工具调用次数限制与超时风控
- **Ollama**：免费本地 LLM 运行工具、无需外网/零 Token 费用、支持代码专用小模型（7B/14B 性价比最优）
