## 平台详解

### Dify：「企业级瑞士军刀」

**核心能力**：Orchestration Studio（工作流编排）+ RAG Pipeline + Agent DSL + MCP Server + LLMOps

**最擅长**：构建复杂、安全、可控的企业级 AI 应用。多模型协同，100+ 模型支持。

**短板**：功能全但不精；学习曲线陡；Bot API 不兼容 OpenAI API。

**一句话选型**：有技术团队、重数据安全、需复杂 AI 应用 → Dify。

### Coze：「人人都是 AI 开发者」

**核心能力**：扣子 Agent + 扣子编程（AI 编程 + 低代码）+ 技能商店 + 多平台发布

**最擅长**：零代码快速构建 AI Agent，一键发布到微信/抖音/飞书等平台。

**短板**：闭源；数据在云端；深度定制不如开源方案；Coze 2.0 后全面收费。

**一句话选型**：非技术团队、快速验证创意、字节生态用户 → Coze。

### n8n：「自动化流程之王」

**核心能力**：可视化工作流 + 400+ 预置集成 + JS/Python 代码节点

**最擅长**：连接一切，把 AI 嵌入现有业务流程。

**短板**：不是专业 AI 开发平台；LLM 能力最弱；上手难度最大。

**一句话选型**：跨系统自动化、复杂业务流程编排 → n8n。

### FastGPT：「知识库轻骑兵」

**核心能力**：RAG 知识库 + 可视化工作流 + OpenAI 兼容 API

**最擅长**：快速构建高质量私有知识库问答系统，轻量高效。

**短板**：功能不如 Dify 丰富；社区不如 Dify 活跃。

**一句话选型**：想快速打造知识库为主的 AI 应用 → FastGPT。

### RAGFlow：「知识库重装兵」

**核心能力**：深度文档理解 + 10+ 种数据预处理 + 知识图谱 + 细粒度 RAG

**最擅长**：处理复杂格式文档（合同/报告/扫描件），追求最高 RAG 质量。

**短板**：部署重（4C16G）；学习门槛最高；不适合轻量场景。

**一句话选型**：对答案准确性和可追溯性有极高要求（法律/医疗/金融） → RAGFlow。

## 选型决策树

```
你的核心需求是什么？
│
├─ 构建 AI Agent/智能体
│  ├─ 零代码，快速上线 → Coze
│  └─ 复杂，需私有部署 → Dify
│
├─ 知识库问答（RAG）
│  ├─ 轻量、快速 → FastGPT
│  └─ 深度、高精度 → RAGFlow
│
├─ 业务流程自动化
│  └─ 跨系统集成 + AI → n8n
│
└─ 企业级 LLM 全链路
   └─ 开发 + 运维 + 监控 → Dify
```

## 组合使用建议

这些平台并非互斥，实际生产环境中常组合使用：

- **RAGFlow/FastGPT 做知识库** + **Dify 做 Agent 编排** + **n8n 串工作流**
- **Coze 做原型验证** → **Dify 做生产部署**
- **n8n 做数据流水线** + **Dify/Coze 做 AI 推理**

---

> 没有绝对完美的工具，只有最适合当前需求和发展阶段的选择。建议从门槛低的平台（Coze/FastGPT）开始，需求复杂后再过渡到更专业的平台（Dify/n8n/RAGFlow）。
